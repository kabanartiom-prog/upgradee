# Tool Evolution (Minecraft Forge 1.20.1, Forge 47.2.0, Java 17)

## Сборка
1. Установите JDK 17.
2. Положите в корень проекта `gradlew`, `gradlew.bat` и `gradle/wrapper/gradle-wrapper.jar` из официального
   Forge MDK 1.20.1-47.2.0 (https://files.minecraftforge.net/net/minecraftforge/forge/index_1.20.1.html),
   либо установите Gradle 8.1.1+ и выполните один раз: `gradle wrapper --gradle-version 8.1.1`.
3. `./gradlew build` (Windows: `gradlew.bat build`) — нужен интернет.
4. Готовый мод: `build/libs/toolevolution-1.0.0.jar` → скопировать в `.minecraft/mods`.

Текстуры/языки/рецепты уже сгенерированы. При желании пересоздать: `python3 tools/generate_resources.py`.

## Использование
- Крафтите модификаторы на верстаке (вкладка «Tool Evolution» в творческом меню / рецепты в JEI/книге рецептов).
- Возьмите модификатор курсором и кликните по инструменту в инвентаре (или наоборот: инструмент курсором на модификатор).
- Максимум 3 слота. Дубликаты и конфликтующие (Скорость I/II/III между собой) установить нельзя.
- Приседание (Shift) отключает Широкую копку, Большую обработку и Лесоруба.

## Рецепты
| Модификатор | Узор (ключи) |
|---|---|
| Скорость I | ` R `/`RIR`/` R ` — R редстоун, I железо |
| Скорость II | `GSG`/`RRR` — G золото, S Скорость I, R редстоун |
| Скорость III | `DSD`/`RRR` — D алмаз, S Скорость II, R редстоун |
| Скорость (топор) | ` R `/`RIR`/` L ` — L любое бревно |
| Скорость (лопата) | ` R `/`RIR`/` C ` — C глина |
| Ускорение (мотыга) | ` R `/`RIR`/` W ` — W пшеница |
| Магнит | `I I`/`IEI`/` R ` — E жемчуг Края |
| Прочность | ` O `/`IDI`/` O ` — O обсидиан, D алмаз |
| Широкая копка (кирка) | `IGI`/`GDG`/`IGI` |
| Широкая копка (лопата) | `IGI`/`GCG`/`IGI` — C глина |
| Большая обработка | `IGI`/`GHG`/`IGI` — H блок сена |
| Лесоруб | `ILI`/`LEL`/`ILI` — E изумруд |
| Вампиризм | `SRS`/`RGR`/`SRS` — S паучий глаз, G слеза гаста |
| Критический удар | `BIB`/`IDI`/`BIB` — B огненный порошок |
